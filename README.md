# 贵阳旅游攻略

访问：https://tataryn123.github.io/guiyang-travel/

手机优先静态页面。18 项美食与 12 项伴手礼按两列展示，正文与 41 张压缩小图直接内置，不依赖脚本或外部图片请求。

默认地图为按地理坐标绘制的路线示意，显示景点、地铁站点连线和直线距离。街道底图由用户点击后加载，网络异常时仍可使用轻量路线图。

发布文件：index.html、leaflet-mobile.js、.nojekyll。GitHub Pages 使用 main 分支根目录。

天气为页面所标日期的趋势参考，不自动更新。图片和信息来源保留在页面中。
