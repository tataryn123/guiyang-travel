# 贵阳旅游攻略

交互式贵阳三日旅行指南，包含天气与穿衣、每日路线与地铁参考、美食和伴手礼。

## 访问

https://tataryn123.github.io/guiyang-travel/

## 发布

GitHub Pages 使用 main 分支根目录。更新 index.html 和引用的 photo-*.webp 图片后自动发布。

## 使用说明

页面适配手机与电脑，景点照片采用轻量 WebP 内嵌，点击地图无需额外下载；美食及伴手礼照片压缩后按需加载，手机端每排两张卡片。地图底图需要联网。
天气为页面标注时间的趋势参考，并非实时更新；门票、营业和交通信息请以官方当天公告为准。
图片与资料来源保留在页面中。
